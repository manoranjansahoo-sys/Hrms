Base Rate Formulations

Establishes daily and per-minute earnings from base compensation.

Per-Day Rate = Base Salary / 30
= ₹{{ payslip.basic_salary|floatformat:2 }} / 30
= ₹{{ payslip.per_day_rate|floatformat:2 }} / day
Daily Hours = {{ period.office_end_time|time:"H:i" }} - {{ period.office_start_time|time:"H:i" }}
= {{ payslip.required_daily_hours }} hours ({{ payslip.required_daily_hours|floatformat:0|add:"0" }}h standard)
Per-Minute Rate = Per-Day / (Hours × 60)
= ₹{{ payslip.per_day_rate }} / ({{ payslip.required_daily_hours }} × 60)
= ₹{{ payslip.per_minute_rate|floatformat:4 }} / minute

Excluded Public Holidays & Sundays; calculates excess leaves & unexcused absences.
